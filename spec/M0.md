# M0 — Walking skeleton ✅ COMPLETE

**Status: complete.** The ZipVoice spike (run in parallel, see `../spike-zipvoice.md`) returned **GO**: ~0.8 s time-to-first-audio at 8 threads on Apple Silicon; no French support.

**Exit criterion (met):** live transcript of your own speech + a spoken sentence, all local; ZipVoice spike verdict documented.

## What was built

- **Shell** — VSCode-style layout from Sapio: icon bar + per-section sidebar + main view (`src/components/layout/app-layout.tsx`, `sidebar.tsx`, `resizable-pane.tsx`), TanStack Router file-based routes (`src/routes/`), next-themes dark/light + OKLCH hue presets (`src/lib/hue-presets.ts`), layout persistence (`src/stores/layout-store.ts`).
- **Config & keychain** — two-way `config.yaml` sync (`src/lib/config-sync.ts`: debounced 500 ms write, 2 s poll, `isPatchingFromFile` loop guard); API keys write through to the macOS keychain, service `Vocalis` (`src/lib/keychain.ts` + `src-tauri/src/commands/keychain.rs`).
- **Models section** — versioned catalog (`catalog/catalog.json`), download manager with progress/resume/sha256/tar.bz2 unpack (`src-tauri/src/registry/download.rs`), per-task active-model slots (`src/stores/models-store.ts`), models installed to `~/.vocalis/models/<task>/<modelId>/`.
- **Rust speech core** — `state.rs` `SpeechState` (lazy-loading engine manager), `audio/` (cpal capture + resample to 16 kHz mono f32), `engines/asr_streaming.rs` (Zipformer), `engines/vad.rs` (Silero), `engines/tts.rs` (Kokoro), pipeline thread with `AtomicBool` stop in a `PipelineRegistry` (`pipeline/mod.rs`), events over a Tauri `Channel` (`asr_pipeline_start`/`asr_pipeline_stop` in `commands/speech.rs`).
- **Playground** — ASR page streaming live mic partials; TTS page synthesizing and playing a wav via `convertFileSrc` (`src/lib/engines/local.ts` is the sole TS↔Rust speech bridge).

## Key patterns established here (reuse everywhere)

- Raw audio never crosses the Tauri IPC boundary during realtime capture; the webview receives only serialized `PipelineEvent`s. File operations pass paths, not bytes.
- Every new Tauri command must be registered in `lib.rs`'s `generate_handler!`.
- New engines: one module per task in `src-tauri/src/engines/`, cached/lazily loaded in `SpeechState`.
- `src/lib/storage.ts` guards all fs access with `isDesktop()`; browser/vitest get no-ops.
