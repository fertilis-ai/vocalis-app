# M1 — System-wide dictation ✅ COMPLETE (closed 2026-07-10)

**Status: complete.** The live walkthrough passed on 2026-07-10: Martin verified hold/release, toggle mode, HUD X/Finish, `⌥Esc`, tray → Stop Dictation, clipboard fallback/restore, tray toggles, and single-pipeline behavior on device.

**Exit criterion (met):** Martin can reliably use Vocalis instead of his previous dictation tool.

## What was built

- **Tray + global hotkey + HUD** — menubar item with quick toggles (privacy, polish, open window, Stop Dictation); global push-to-talk `⌥Space` (hold + toggle modes, configurable) via `tauri-plugin-global-shortcut` (`src/lib/dictation/hotkey.ts`); compact floating HUD window (`src/routes/hud.tsx`, `src/components/dictation/dictation-hud.tsx`) using `app.macOSPrivateApi` transparency and `core:window:allow-hide` capability.
- **Pipeline** — mic → VAD → streaming Zipformer ASR → CT-Transformer punctuation, all in Rust (`src-tauri/src/pipeline/dictation.rs`, commands in `commands/dictation.rs`). Dictation audio is never persisted; transcript history (last 50, text only) in `src/lib/dictation/history.ts`.
- **Text injection** — clipboard-swap + synthesized ⌘V with previous-clipboard restore (`src-tauri/src/commands/inject.rs`, `arboard` + `core-graphics`); degrades to "copied to clipboard" + notification when Accessibility is denied.
- **LLM polish** — optional pass (filler removal, self-correction, light formatting) via pi-ai (`src/lib/llm/dictation-polish.ts`); forced off in privacy mode unless the polish model is local.
- **Dictation settings** — hotkey/mode/polish/history in `src/components/settings/dictation-settings.tsx`.

## Defects found and fixed (revision pass, 2026-07-10)

Preserved because the lessons still apply to any second-window / tray feature:

1. **HUD window had no API keys** — keys are excluded from localStorage under Tauri and config-sync only runs in the main window, so `polishDictation` always fell back to raw text. Fix: HUD reloads keys from the keychain on provider changes.
2. **Two webviews, two stale stores** — the main window and HUD had independent settings stores. Fix: `src/lib/settings-broadcast.ts` — main window broadcasts synced settings (`settings-sync` event + tray mirroring), the HUD mirrors them, and a `settings-sync-request` handshake runs at HUD startup. HUD-originated changes (e.g. the polish button) emit the shared `dictation-settings` event so they persist through the main window's config-sync instead of dying in the HUD-local store. **Rule: any state a second window can read or write must flow through this broadcast, never through its local store alone.**
3. **Tray check items never reflected real state** — fixed with a `TrayToggles` managed state + `tray_set_toggles` command.
4. **HUD engine chip was hardcoded** — now shows the active `asr-streaming` model slot.

Also from stabilization: repeated shortcut events could launch overlapping pipelines → the HUD and the Rust registry now **reject concurrent starts**, pipelines have a **90-second watchdog**, and a missed-release race was fixed by keeping one HUD event listener with stable callback refs. `⌥Esc` and tray → Stop Dictation are native recovery paths that stop capture even if the HUD is unresponsive.

UI was restyled from hardcoded colors to OKLCH theme tokens, and settings pages use Sapio's idiom (h-10 header bar, `max-w-2xl` bordered sections, muted icons).
