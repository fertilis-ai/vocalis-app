## 4. File import pipeline ✅ code-complete (2026-07-10)

**Build record.** `cargo check`/`cargo test` clean (63 lib+integration tests, 5 new pure-core: chunk/punctuation/progress/settle + shared speaker helpers); `check-types`/`test:run` (273, 5 new) green; `lint` exit 0; `vite build` ok. No new clippy warnings (same 2 pre-existing in `resample.rs`/`lib.rs`).
- **Rust decoders** (`audio/decode.rs`, `symphonia` dep with mp3/aac/alac/isomp4/flac/wav/pcm features): `decode_to_16k_mono(path)` probes the container by content (+ extension hint), decodes, downmixes (`downmix_to_mono`) and resamples (`LinearResampler`) to 16 kHz — the same downmix+resample the live path uses. A single corrupt frame is skipped, not fatal.
- **`import_audio(sessionId, path)` command** (`commands/speech.rs`): decodes → writes `sessions/<id>/audio.wav` (16 kHz mono, the retained audio + the input both import paths consume) → returns `{audioPath, durationMs}`. Originals untouched (spec §4).
- **Local import run** (`pipeline/import.rs`): `session_import`/`session_import_cancel` commands → thread-owning batch job registered in `PipelineRegistry` (cancel + deletion guard), single-session guard via the shared `session_active` atomic. Algorithm: diarize whole clip → per-diarization-span batch ASR (spans sub-chunked to ≤28 s for whisper's window) → conditional punctuation (only when whisper left none) → per-span embed + enrolled-Person match. Streams the **same events as the live pipeline** — `SpeakerTurn` per turn, `Progress {fraction}` (new event) for the meter, then a settled `Refined` + `Stopped` — so item 5 renders live and imported transcripts through one handler. Cancel between spans emits `Stopped` with no `Refined`; an all-silence clip settles to an empty transcript.
- **Shared speaker core** (`pipeline/speakers.rs`): extracted `letter_label`, `relabel_by_first_appearance`, `accumulate`, `EnrolledSpeaker`, `match_person`, and `cluster_means_to_people` out of `live_session.rs` (which now consumes them) so the import settle pass reuses the exact same first-appearance renumbering + per-cluster person matching.
- **TS bridge** (`lib/engines/local.ts`): `importAudio`, `startImport`/`stopImport`, `progress` event on the `PipelineEvent` union.
- **Import orchestrator** (`lib/import/run-import.ts`): normalizes audio, marks the session `mode:"import"` + `status:"processing"`, then routes by the resolved batch-ASR engine — **local** → the Rust pipeline (streams provisional turns, settles on `refined`); **API** → an M2 batch adapter (Groq/OpenAI/ElevenLabs/Deepgram) for text+words, plus a diarization step (Deepgram when diarization is routed there, else the local offline diarizer) merged into speaker turns by the pure, unit-tested `lib/import/segments.ts:mergeWordsWithDiarization`. Persists transcript + `SpeakerRef[]` to the session store; failures set `status:"error"` with the message. Never silently swaps local↔API (spec §3.4).
- **Import dialog** (`components/chat/import-dialog.tsx`, wired into the chat "New… → Import audio file…" flow): file picker → confirm source, **`EngineChip` batch-ASR override** + language select, Start; shows a live progress bar. The session is created only on Start (a cancelled dialog leaves nothing behind). `speakerLetter` added to `speaker-labels.ts` (mirrors Rust `letter_label`).
- **Deferrals / caveats:**
  - **Audio retained as WAV**, not FLAC — same sanctioned fallback as items 2/3 (`sessions/<id>/audio.wav`).
  - **Local path uses diarize-first, per-span ASR** (not whole-clip transcribe + word→span merge): gives real progress and bounds whisper's input length, at the cost of cross-span ASR context. Documented v1 choice.
  - **API imports don't match enrolled People** — API ASR returns no embeddings (spec lists Person matching under the local path only); speakers stay `Speaker A/B…`. A failed/absent diarizer degrades an API import to a single unlabeled speaker rather than erroring.
  - **Not exercised in the running app** — needs a `desktop:dev` pass over a real audio file with local models installed; the API path additionally needs real keys (shares the M2 item 9 keyed-live-pass gate). The imported transcript is written to the session store but **rendering it (bubbles + scrubber) is item 5** — `chat-content` still shows the session placeholder.

Command `import_audio(path) -> {pcmWavPath, durationMs}` writing a normalized temp wav; keep originals as-is per spec §4.
- **Import run:** `session_import(sessionId, filePath, engineId, params)` — long batch job on a blocking thread with progress events (percent by decoded duration) and cancel (registry `AtomicBool`). Local path: whisper batch ASR (+ punctuation if the engine leaves none) + offline diarization + Person matching.
