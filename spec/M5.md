## 1. Clone-reference flow (People)

- Guided clean recording, ~10–60 s, in the Person profile view: reuse `pipeline/recorder.rs` + `LevelMeter` with **quality checks** — reject and prompt re-record on clipping (peak ≥ ~0.99), too-low level (rms below floor), or excessive noise (rms during VAD-silence above threshold; reuse the Silero VAD to find silence). Show the check results per take.
- The reference needs a **transcript**: default to running the recorded reference through local Whisper (`asr_transcribe_file`) and letting the user correct the text — ZipVoice conditions on (refAudio, refText).
- Store under `people/<id>/clone-ref/*.flac` + transcript in `profile.json` (`cloneRef: {samples, transcript, consentConfirmed}`).
- **Consent rule (spec §2.4):** cloning a voice other than your own requires ticking "I have this person's consent" — persist the confirmation; profiles show which flows (enrollment/clone) they've completed.

## 2. ZipVoice local synthesis

- Model: `clone-tts/zipvoice-distill-int8` is already in the catalog (zh/en). Verify the `sherpa-onnx` crate (1.13.4) exposes ZipVoice offline TTS; if not, FFI to the C API for this engine only (spec §7.2).
- Rust: extend `engines/tts.rs` or add `engines/tts_zipvoice.rs` implementing the same `Tts` shape (`synth(text, voice, params) -> WavPath`), where a clone voice = `{refAudioPath, refText}`. Cache instance in `SpeechState`; **lazy-load with a "warming up" event** (spec §3.3) — ZipVoice is heavyweight, it must not be resident by default, and the EngineManager LRU should be able to evict it (spec §7.7).
- Threads matter: the spike hit 0.8 s TTFA at **8 threads** — expose `numThreads` in the engine config and default it sensibly for the machine.
- Command: reuse `tts_synthesize` with a clone-voice reference; output to `~/.vocalis/cache/tts/` under the M2 LRU cap.
- **Chat integration:** sentence-chunked synthesis through the M4 playback queue (ZipVoice is batch-only — never streaming, spec §9). Profile on-device: time-to-first-audio target < 1.5 s including warm-up amortization; log `Metrics` so the debug pane shows it.
- **No French** — the descriptor's `langs` must say so, and pickers should show it as an eligibility note. Fallback path if quality disappoints (spec §7.1): F5-TTS ONNX behind the same trait; worst case clones are ElevenLabs-only.
- Tests: `--ignored` real-model integration test (synthesize from a fixture reference; assert non-empty audio + duration sanity + TTFA logged).
